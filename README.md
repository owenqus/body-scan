# Body Scan V0.1 — 西装数字量体原型

这是第一版工程验证原型，目标不是立即用于生产，而是回答一个关键问题：

> 普通手机是否能稳定采集足够好的身体几何数据，供高定西装项目继续开发？

## V0.1 已实现

- 浏览器调用手机/电脑摄像头
- MediaPipe Pose Landmarker 实时人体关键点
- 人体 segmentation mask（轮廓）
- 引导采集：正面 / 右侧 / 背面 / 左侧
- 输入真实身高后进行厘米尺度校准
- 初步计算：
  - 胸围（正面宽度 + 侧面厚度椭圆近似）
  - 腰围
  - 臀围
  - 肩宽
  - 左右袖长
  - 左右肩高度差
  - 胸/腰/臀正面宽度与侧面厚度
  - 侧面肩-胯水平偏移
- 生成可旋转的 3D 体型代理模型
- 导出 JSON
- 导出真人验证 CSV

## 重要：这不是生产版尺寸

V0.1 使用的是“身高校准 + 轮廓 + 关键点”的几何估算。它还没有加入：

- 相机内参标定
- 镜头畸变修正
- 真实 360° 多视角重建
- SMPL-X / STAR 等参数化人体 Mesh 拟合
- 深度融合
- 不同手机型号的校准曲线
- 衣物厚度修正
- 版师 Fit Rule Engine

因此当前输出只能用来做 A/B/C 测试：

A. 我们的扫描结果  
B. 第三方商业 API（后续加入）  
C. 版师人工量体 + 实体号衣判断

## 怎么运行

### 方法 1：电脑先测试

在这个文件夹打开终端：

```bash
python -m http.server 8080
```

然后 Chrome 打开：

```text
http://localhost:8080
```

浏览器会询问摄像头权限。

### 方法 2：手机测试

手机浏览器调用摄像头通常要求 HTTPS。最简单的方式是把整个文件夹部署到 Vercel、Netlify 或 GitHub Pages，然后用手机打开 HTTPS 地址。

> 不要直接双击 `index.html`；摄像头与 WebAssembly 模型需要通过 HTTP/HTTPS 提供。

## 拍摄方法

1. 穿贴身 T 恤 + 贴身裤子。
2. 手机大致在腰到胸高度，尽量保持水平。
3. 全身必须入镜，包括头顶和脚底。
4. 距离通常 2.5–4 米，取决于摄像头视角。
5. 正面与背面：手臂离开身体约 15–25°。
6. 侧面：手臂不要遮住腰线和腹部轮廓。
7. 输入真实身高。
8. 按顺序拍四个视角。
9. 点击“计算尺寸”。
10. 导出验证 CSV，让版师填写手工数据。

## V0.2 的明确目标

下一版不再只依赖四张图，而会进入：

**15–30 秒 360° 视频 → 自动抽取高质量帧 → 多视角拟合 → 参数化 Tailoring Body Mesh**

V0.2 重点输出：

- 左右肩斜角
- 前肩 / 后肩
- 胸厚 / 背厚
- 腹部前突量
- 上背曲率
- 骨盆倾斜
- 身体横截面
- 前后 Balance 所需几何参数

## 数据验证建议

第一轮先做 20 人，每人扫描 3 次，并由同一个版师人工量体。详见 `VALIDATION_PROTOCOL.md`。
